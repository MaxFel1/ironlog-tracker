# IRON.LOG — HTML-Datei aktualisieren

So tauschst du eine neue Version der `index.html` auf GitHub aus.
Deine eingegebenen Daten (Training, Gewicht, Ernährung) bleiben dabei erhalten,
weil sie lokal am Handy gespeichert sind – nicht in der Datei.

## Variante A: Datei direkt ersetzen (empfohlen, am schnellsten)

1. Öffne dein Repository auf github.com
2. Klick oben auf **Add file** → **Upload files**
3. Zieh die neue `index.html` ins Fenster (gleicher Dateiname → ersetzt automatisch)
4. Unten **Commit changes** klicken
5. Nach ~1 Minute ist die neue Version online

## Variante B: Inhalt bearbeiten (wenn nur Kleinigkeiten geändert werden)

1. Im Repository auf die Datei **index.html** klicken
2. Oben rechts auf das **Stift-Symbol** (Edit this file)
3. Alten Inhalt komplett markieren + löschen, neuen Inhalt einfügen
4. **Commit changes** klicken

## Am Handy: neue Version laden

- App vom Startbildschirm öffnen
- Einmal **die Seite neu laden** (in Chrome: nach unten ziehen zum Aktualisieren)
- Falls die alte Version „hängt": App schließen, kurz warten, neu öffnen
  (der Offline-Cache aktualisiert sich beim nächsten Online-Start)

## WICHTIG: Vor jedem Update ein Backup machen

Auch wenn Updates die Daten normalerweise nicht löschen – sicher ist sicher:

1. App öffnen → **Stats** → **Daten** → **Export (JSON)**
2. Die JSON-Datei aufbewahren
3. Falls doch mal Daten fehlen: **Import (JSON)** und die Datei wieder laden

## Daten auf ein neues Handy übertragen

1. Altes Handy: **Export (JSON)** → Datei z.B. per Mail/Cloud auf neues Handy
2. Neues Handy: App-URL öffnen → installieren → **Import (JSON)** → Datei laden
